# CorporateLuxe property earnings calculator

The public root and `corporateluxe.html` present CorporateLuxe in partnership with AirLandlords, using the existing black/gold design and enquiry receiver.

1. Full UK postcode, bedrooms (studio to 10), current/expected monthly rent and email.
2. Letting duration, whole property/private room, preferred start.
3. Full name, mobile and enquiry-only consent.
4. Confirmed private Sheet write, then the income projection, twelve-month breakdown, annual comparison and PDF download, followed by call/message options.

Public percentage/condition controls remain removed. The model uses the owner's specified 40% benchmark, stated by the owner to be derived from CorporateLuxe's data, and preserves the original month-level rounding and seasonality. The underlying dataset has not been imported or independently checked. Wording attributes the projection to CorporateLuxe's data and seasonal assumptions; it does not claim a live postcode valuation or guaranteed income. Figures are before management fees, platform fees, bills and other costs.

`estimate.js` contains the browser projection and PDF generator, using the same jsPDF version as the old calculator. `enquiry-v3.js` validates each step, preserves Back answers, waits for a matching confirmed receipt and verifies the server's projection before revealing it. The server recalculates the estimate itself. Contact data stays in memory until submission; no marketing emails or subscriptions are created.

For rent £1,800 and the retained normal-condition model, winter months are £2,016; base months £2,520; summer months £3,024. Annual £29,736; rounded monthly average £2,478; standard annual £21,600; annual difference £8,136. Seasonality means the annual average is not a flat 40% above the rent. The result and PDF show the actual summed totals.

`admin.html` preserves the original internal calculator and convenience PIN 1234. The static PIN is not secure authentication.

## Storage

`Code.gs` is deployed as version 6 of the existing web-app endpoint in `config.js`, executing as the existing AirLandlords owner with the previously granted Sheets scope. It preserves the old payload handler and server calculation for compatibility, and accepts qualified `corporateluxe-v2` enquiries plus `corporateluxe-v3` projection enquiries. The private Sheet remains private. No read endpoint exposes lead data.

Existing columns A:T and all previous leads remain intact. Column F now stores bedroom count for V2. U:AA add Full Name, Letting Duration, Property Scope, Start Time, Estimate Status, Brand and Flow Version. Source is `Property Earnings Calculator`, status `New Lead`, and the timestamp is generated by the receiver. V2 estimate columns G:J remain blank. V3 fills G:J with average, annual, standard annual and difference; P:T hold the entered monthly rent, standard rent, benchmark, normal-condition assumption and twelve monthly amounts. V3 Estimate Status is `Short-let income projection`. Formula prefixes are escaped. Consent, fields and enum values are checked on the server; a lock and field-bound request ID guard retries. Origin/honeypot checks are only lightweight abuse deterrents, not authentication.

Synthetic test enquiries are labelled `Test - do not contact` after readback. Do not follow them up.

4. Wait for the GitHub DNS check and certificate; enable Enforce HTTPS when available. Never bypass certificate warnings.
5. Update the social image URLs in both HTML files to the custom-domain absolute URL and social captions to the final branded URL. Relative asset/form/privacy links already work at a domain root. The receiver already allows `https://calculator.corporateluxe.co.uk` and CorporateLuxe website origins.

## Validation

Run `node verify.mjs`: retained legacy server calculation/receipt, retries, conflicts, malformed submissions, enquiry consent, formula escaping, plus qualified-enquiry storage, added columns, V2 compatibility, V3 server projections, rent validation, comparisons against the retained original calculator, allowed origins and failure handling. Browser QA covers property → plans → contact → confirmed write, mobile layout and saved Sheet field readback. Tests use synthetic `calculator-test@example.com` / `07700 900123` contacts.

No social posts, marketing emails or ads are sent automatically. Campaign artwork uses an AI-generated illustrative interior, not a claimed managed property. Prepared captions can describe the income projection, monthly breakdown and report.
